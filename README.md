# How I Use AI in Business Development

I prefer a hybrid architecture:

```text
STRUCTURED DATA
      +
DETERMINISTIC COMMERCIAL LOGIC
      +
EXPLAINABLE OUTPUTS
      +
OPTIONAL AI ASSISTANCE
      +
HUMAN JUDGMENT
```

Across the portfolio, deterministic logic controls scores, thresholds, ranking and commercial priority wherever possible.

AI is used for tasks such as:
- interpretation
- account briefs
- discovery questions
- message drafting
- commercial hypotheses
- structured next-step support

Unverified information should remain a **hypothesis or question**, not be presented as fact.
